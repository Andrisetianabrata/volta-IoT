## Temuan yang sudah ditutup

1. (LOW, ditutup) `role=tablist/tab` tanpa navigasi panah dan tanpa
   `tabpanel`. Diperbaiki dengan melepas peran tab: kontrol Masuk /
   Daftar sekarang `role="group" + aria-pressed` (pilihan toggle,
   bukan tab; tidak ada tabpanel yang disembunyikan). Tab/Enter dan
   focus visible tetap jalan. File: `components/login-form.tsx`.
2. (LOW, ditutup sebagian) Verifikasi live: `npm run dev` melayani
   `/login` dengan HTTP 200 dan copy yang benar ("Masuk ke VOLTA.",
   "Kembali ke situs", mode Daftar). `tsc` + `next build` bersih.
   Sisa untuk manusia: klik tiap kontrol di browser nyata
   (belum ada run headless di sesi ini).
